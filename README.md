# The Smallest Agent · React Native + Expo + TypeScript

Independent edition 10: a real React Native application for Android, iOS and web, plus a separate Node.js TypeScript Claude Agent SDK server. Five routed lessons preserve the lab state through an Expo Router layout provider. Large text, pastel cards, persistent dark mode, syntax-colored code, a 16-step UML sequence, source explanations and real message streaming are included.

## Windows quick start

Use Node.js 24 LTS. From **Lesson 0** in PowerShell:

```powershell
cd .\10-smallest-agent-react-native-expo
npm install
npm --prefix backend install
if (!(Test-Path backend\.env)) { Copy-Item backend\.env.example backend\.env }
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad backend\.env
npm run dev
```

Replace only `ANTHROPIC_API_KEY` in **backend/.env** with your own key. Open **http://localhost:5100**. API: **http://127.0.0.1:8500/api/health**. Stop both processes with Ctrl+C. `Start-Application.ps1` locates this folder regardless of your terminal's starting directory. No Python, virtual environment, .NET or prior edition is required.

`npm run dev:api` and `npm run dev:web` run separately. `npm run start` runs Expo with LAN access for a device. A missing key allows the interface and lessons to work; requests fail safely without calling Claude. Health reports presence, not authenticated readiness.

## Environment files

**backend/.env** is private and loaded relative to the backend module, with process-environment precedence. Key required for inference; empty CLAUDE_MODEL uses SDK default. AGENT_MAX_TURNS defaults to 1 and accepts integers 1–10. AGENT_SYSTEM_PROMPT is optional. API_HOST defaults to 127.0.0.1, API_PORT to 8500. ALLOWED_ORIGINS is an exact comma-separated browser allowlist including protocol and port. Restart the backend after editing.

**Root .env** is public: `EXPO_PUBLIC_API_URL=http://127.0.0.1:8500`. Never put credentials into any EXPO_PUBLIC variable. Expo embeds these values in the bundle; clear/restart or rebuild after changes. Neither real .env file is committed or generated by the scaffold.

## Run on a phone or emulator

For a physical phone use the PC's LAN IP in EXPO_PUBLIC_API_URL, such as http://192.168.1.20:8500, set API_HOST=0.0.0.0 privately, and use the same network. Permit development ports through Windows Firewall as needed. A phone's localhost points to itself. Android emulator uses http://10.0.2.2:8500. Browser access from another computer also requires its exact web Origin in ALLOWED_ORIGINS.

```powershell
# Terminal 1, application root
npm run dev:api
# Terminal 2, application root
npm run start -- --clear
```

SDK 58 requires a compatible Expo Go or development build. Since expo-dev-client is included, the development server defaults to a development build; press `s` to switch to Expo Go or run `npm run start -- --go` when your Expo Go supports SDK 58. Otherwise use a development build. EAS requires an Expo account and signing credentials; no cloud build/upload is performed automatically:

```powershell
npx eas-cli@latest build --profile development --platform android
npx eas-cli@latest build --profile development --platform ios
```

Install the generated build and connect it to Expo's development server. Local Android builds require Android Studio/JDK and `npx expo run:android`; local iOS compilation requires macOS/Xcode. Native permissions and cleartext local-network access vary by OS: production must use HTTPS. Web remains runnable directly on Windows.

## Checks and builds

```powershell
npm run generate:lesson
npm run typecheck
npm run lint
npm test
npm run build
npm run build:native
npx expo install --check
npx expo-doctor
```

Root and backend each have a lockfile; use npm ci and npm --prefix backend ci for repeat installs. build compiles the Node backend into backend/dist and exports Expo web into dist. build:native exports Android/iOS JS/assets into dist-native; these are not signed installable apps. `npm --prefix backend start` runs the compiled API. After stopping Expo development, `npm run preview` serves the exported web app on port 5100 with lesson deep-link fallback. Serve dist in production with a static host that falls back to index.html for lesson URLs. The API must run separately; static export does not embed it. Configure a public HTTPS API URL before building for production, add authentication/rate and cost limits, and restrict CORS to your deployed browser origin. Native clients have no browser Origin, so CORS is not authentication.

## Contracts and safety

GET /api/health exposes status and api_key_configured. POST /api/agent/query accepts {prompt} and returns result, num_turns, duration_ms, total_cost_usd and is_error. POST /api/agent/stream accepts the same JSON and emits SSE message events (safe SystemMessage, AssistantMessage, UserMessage, ResultMessage or OtherMessage), then done. SSE failures emit error without done. Streaming means SDK messages rather than token deltas. expo/fetch provides native readable response streams.

Requests are bounded at 32 KiB and trimmed 1–4000 characters: malformed JSON 400, disallowed browser origin 403, oversized 413, wrong media type 415, invalid prompt 422. Missing key gives query 503 or an SSE error; provider failures give query 502 or safe SSE errors. No raw provider exception is exposed. Built-in tools, autoapprovals, settings, skills, plugins, MCP and persisted sessions are disabled. Each conversation closes in finally, and disconnect/cancel/three-minute deadlines abort work. Safe projection excludes thinking, tool arguments and raw configuration, and redacts exact key occurrences.

The client requires a final result plus done, retains is_error, caps visible timeline rows at 500 without dropping final results, and renders answers as native text. Supported Markdown: headings, bold, HTTP(S) links and colored fenced code. Other markup is literal text; model HTML and images never execute. Copy is supported with Expo Clipboard; export downloads in browsers and shares a cached file on native platforms.

The sequence diagram and 16 actual-source cards regenerate together. Steps 5–6 describe the SDK-owned network exchange using the application query/iterator boundary; they do not pretend the app implements the provider transport. Unknown languages display plain safe text. Tests inject SDK messages and spend no API credits. See VERIFICATION.md for actual checks and platform limitations.
